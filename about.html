关于这个榜单About this leaderboard

在一台 Apple Silicon Mac 上，用 MLX 本地运行开源 TTS 模型，按统一的题目和自动指标横向比较。结构和指标定义参考了 Hugging Face 的 Open TTS Leaderboard；差别在于我们是本地 MLX 推理、模型是各自的 MLX 移植版，并且额外测了克隆、情感、方言等能力。Open-source TTS models run locally with MLX on one Apple Silicon Mac and compared on the same items with automatic metrics. The structure and metric definitions follow the Hugging Face Open TTS Leaderboard; the differences are that everything runs locally as MLX ports and that cloning, emotion and dialect abilities are measured as well.

指标Metrics

指标Metric↕含义What it is
质量分Quality score⬆只统计该模型已测能力的加权分（9 个能力、权重见首页），同组内差 3 分以内视为同档。Weighted score over the abilities the model was actually tested on (9 abilities, weights on the overview); a gap within 3 points inside a group counts as the same tier.
全能分All-round score⬆不支持、未测的能力按 0 计入，所以同时反映质量和能力广度。Unsupported and untested abilities count as 0, so it reflects breadth as well as quality.
WER / CER⬇Qwen3-ASR 1.7B 转写后与目标文本比：中日韩泰等按字（CER），其余按词（WER）。与 HF 榜单同一个 ASR；文本归一化不完全相同，不要和论文数字逐位对比。Qwen3-ASR 1.7B transcript vs the target text: per character (CER) for Chinese, Japanese, Korean, Thai and similar, per word (WER) otherwise. The same ASR as the HF leaderboard; text normalisation is not identical, so do not compare digits with papers.
SIM⬆说话人相似度。克隆分取 ECAPA、CAM++ 与 Seed-TTS-Eval 官方 WavLM-Large 三个声纹模型的平均，ECAPA 或 CAM++ 判“不是同一人”、或没念出目标文本时封顶。公开口径评测页单独报官方 WavLM 的 SIM，能和论文、HF 榜单直接对照。Speaker similarity. The clone score averages three speaker models (ECAPA, CAM++ and the official Seed-TTS-Eval WavLM-Large) and is capped if ECAPA or CAM++ says it is a different person or the target text was not spoken. The public-metric page reports the official WavLM SIM on its own, comparable with papers and the HF leaderboard.
UTMOS⬆预测自然度（1–5）。克隆出的声音会继承参考音频的音质，所以参考音质低于 4.0 的样本按“相对参考有没有变差”折算，上限 4.0。UTMOS 只在英文上训练，HF 榜单只报英文；我们也对其他语言计分，但其他语言的 UTMOS 只能当粗略参考。Predicted naturalness (1–5). A cloned voice inherits its reference's recording quality, so for references below 4.0 the score is rescaled by how much the output lost relative to the reference, capped at 4.0. UTMOS is English-trained and the HF leaderboard reports English only; we also score other languages, but there UTMOS is only a rough guide.
ES, 情绪提升emotion lift⬆emotion2vec 情感向量与情感参考音频的余弦相似度（IndexTTS2 论文的指标），以及扣掉“同一个人”影响后的提升。Cosine of the emotion2vec embeddings of the output and the emotion reference (the IndexTTS2 paper's metric), and the lift after removing the effect of being the same person.
RTF⬇生成耗时 ÷ 音频时长。各模型的历史 RTF 计时范围不完全一致，只能看量级；HF 榜单用的是同一块 H200 上的批量 RTFx，我们是单机单条。Generation time ÷ audio duration. Historical RTF timings do not all cover the same scope, so read orders of magnitude; the HF leaderboard uses batched RTFx on one H200, ours is one clip at a time on one Mac.
TTFA⬇流式首包延迟：从请求到第一个非空音频块的毫秒数，批大小 1，模型已加载。只测了有流式接口的模型。Time to first audio: milliseconds from the request to the first non-empty audio chunk, batch size 1, model already loaded. Measured only for models with a streaming interface.
参数量、许可证Size, licence–读自上游 Hugging Face 模型卡，卡片没写参数量的留空，不估计。MoE 报总参数。许可证按模型卡标注，商用前请读原文。Read from the upstream Hugging Face model card; where a card states no size it is left blank, never estimated. MoE shows total parameters. Licences are as labelled on the cards; read the text before commercial use.

HF 榜单还用了 CV3-Eval（9 种语言）、MiniMax 多语言集（24 种语言）和 Neyshekar（波斯语），我们没有跑，那些语言用自建题库的朗读题代替，见首页的“按语言比较”。The HF leaderboard also uses CV3-Eval (9 languages), MiniMax Multilingual (24 languages) and Neyshekar (Persian). We did not run those; those languages are covered by our own reading items, see “Compare by language” on the overview.

  • 2026-11-26
    修正 Ming3 Tiny 的 MLX 移植错误，全部重测Fixed porting bugs in Ming3 Tiny and retested it in fullMing3 Tiny 在部分参考音上只生成静音、有的句子停不下来。对照官方源码找到语言模型的三处移植错误：MLA 注意力没有因果掩码（预填充时前面的词能看到后面的词）、RoPE 没按配置用交错排列、MoE 路由没用 fp32；另按官方任务协议补上“Target language”行、把指令放在助手角色之后、情绪与方言只用模型训练时的取值。修复后 Seed-TTS 英文错误率 29.00% → 0.61%、中文 17.58% → 0.61%，不再出现静音；主榜 32 道题各重跑 3 次（控制题由同一 Gemini 评委重评、方言重新核验），总分 70.1 → 79.7，内容准确 75.2 → 86.1，克隆 42.3 → 80.9。代价是速度：提示里多了官方的控制指令，而移植版的 MoE 逐词预填充较慢，RTF 中位数 1.54 → 2.54。四川话仍判为普通话，未通过。Ming3 Tiny produced pure silence on some references and ran on without stopping on some sentences. Against the official source we found three porting bugs in its language model: MLA attention had no causal mask (during prefill earlier tokens could see later ones), RoPE ignored the configured interleaved layout, and the MoE router did not run in fp32. Following the official task protocol we also added the "Target language" line, moved instructions after the assistant role, and limited emotion and dialect values to the ones the model was trained on. After the fix, Seed-TTS English error fell from 29.00% to 0.61% and Chinese from 17.58% to 0.61%, with no silent outputs; all 32 board items were rerun with 3 takes each (control items rejudged by the same Gemini judge, dialects re-verified): overall 70.1 → 79.7, content 75.2 → 86.1, clone 42.3 → 80.9. The cost is speed: prompts now carry the official control instruction and the port's per-token MoE prefill is slow, so median RTF went from 1.54 to 2.54. Sichuanese is still classified as Mandarin and fails.
  • 2026-11-26
    修正 Ming3 0.5B 克隆时生成过早停止Fixed Ming3 0.5B stopping too early when cloning和 Hugging Face 开放 TTS 榜对照时发现，Ming3 0.5B 在 Seed-TTS 上的错误率比对方高很多（英文 7.7% 对 1.0%）。原因是 MLX 移植版把参考音频的对齐补零加在结尾，官方代码加在开头：模型从参考音频的结尾接着生成，结尾多出的静音会让它以为话已说完，有的句子只生成 0.2 秒。改为补在开头后重跑：Seed-TTS 英文错误率 7.74% → 0.91%、中文 7.14% → 0.65%，与官方榜接近；主榜 4 道克隆题各 3 次采样重新生成，克隆分 71.7 → 77.8，总分 80.4 → 81.4。Ming3 Tiny 的官方代码本来就补在结尾，它在部分参考音上生成静音是另一个问题（已在下一条修复）。Comparing with the Hugging Face Open TTS Leaderboard showed Ming3 0.5B misreading far more on Seed-TTS than there (English 7.7% vs 1.0%). The MLX port padded the reference audio at the end, while the official code pads at the front: the model continues from the tail of the reference, so trailing silence made it treat the utterance as finished, and some clips were only 0.2 s long. With front padding: Seed-TTS English error 7.74% → 0.91%, Chinese 7.14% → 0.65%, close to the official board; the 4 main-board clone items were regenerated with 3 takes each, clone score 71.7 → 77.8, overall 80.4 → 81.4. The official Ming3 Tiny code pads at the end, so its silent outputs on some references are a separate problem (fixed in the next entry).
