公开口径评测Public-metric benchmarks

总榜用的是我们自建的 84 道题。这里补两套和公开论文、Hugging Face Open TTS Leaderboard 同口径的评测：Seed-TTS-Eval 的官方提示音频抽样，以及仿照 IndexTTS2 论文的情感克隆测试。The main leaderboard uses our own 84 items. These two add evaluations on the same footing as public papers and the Hugging Face Open TTS Leaderboard: a sample of the official Seed-TTS-Eval prompts, and an emotion-cloning test modelled on the IndexTTS2 paper.

① Seed-TTS-Eval 抽样（英文 / 中文）① Seed-TTS-Eval sample (English / Chinese)

用官方提示音频克隆官方目标文本。指标与 HF 榜单一致：英文 WER、中文 CER（Qwen3-ASR 1.7B），SIM 是 Seed-TTS-Eval 官方 WavLM-Large + ECAPA-TDNN 的余弦相似度，UTMOS 只报英文（UTMOS22 只在英文上训练）。Clone the official prompt clip and say the official target text. Same metrics as the HF leaderboard: WER (English) / CER (Chinese) from Qwen3-ASR 1.7B, SIM = cosine of the official Seed-TTS-Eval WavLM-Large + ECAPA-TDNN embeddings, UTMOS for English only (UTMOS22 is English-trained).

抽样很小：全集英文 1000 条、中文 2000 条，本地模型跑不动，每语言固定种子随机抽 30 条（Pocket 与 IndexTTS2 越南语版只有英文）。名次相近的模型差距不显著，只能看量级，和论文数值对照时要带上这个前提。Small sample: the full sets have 1000 (English) and 2000 (Chinese) lines, too many for local models, so each language is a fixed-seed random sample of 30 (Pocket and IndexTTS2-Vietnamese are English only). Models close in rank are not significantly different; read orders of magnitude, and keep this in mind when comparing with paper numbers.

② 情感克隆集（RAVDESS，12 人 × 7 情绪 × 3 句）② Emotion-cloning set (RAVDESS, 12 actors × 7 emotions × 3 sentences)

IndexTTS2 论文用自己招人录的情感集，没有公开，所以用 RAVDESS 做等价集（CC BY-NC-SA，仅限非商业；不在 IndexTTS 论文的训练数据里）。参考音频是演员的情绪录音，目标是一句中性内容的新句子，情绪只能来自参考音频，命令里没有情绪标签。只测能接收情感参考音频的 5 个模型，每个 252 条。The IndexTTS2 paper uses an emotion set it recorded itself and did not release, so we built an equivalent from RAVDESS (CC BY-NC-SA, non-commercial; not in the IndexTTS paper's training data). The reference is an actor's emotional clip and the target is a new, emotionally neutral sentence, so any emotion must come from the reference; no emotion label is given. Only the 5 models that accept an emotion reference audio are run, 252 clips each.

③ 流式首包延迟（TTFA）③ Streaming latency (TTFA)

从发出请求到收到第一个非空音频块的毫秒数，模型已加载并预热，批大小 1，用 Seed-TTS 英文提示音频克隆，3 次不计时预热后计时 20 次；参考音频的预处理计入（它是请求的一部分），模型加载不计。只测有流式接口的模型。Milliseconds from issuing a request to the first non-empty audio chunk, with the model loaded and warmed up, batch size 1, cloning from the Seed-TTS English prompt: 3 untimed warm-up requests, then 20 timed. Reference preprocessing counts (it is part of the request); model loading does not. Only models with a streaming interface are measured.

怎么读：这是在本机（Apple Silicon）上测的，不是 HF 榜单的 H200/A100/CPU，只能和本榜单内部比。各项目的流式粒度不同：Qwen3、VoxCPM2、Pocket、Audio8、MOSS、Breeze 是按固定时长的音频块（interval 列），IndexTTS 是按完成的文本段（不是逐 token），短句只有一段，所以它的首包就是整句生成完的时间。首块越长，延迟里包含的音频越多，不能只看毫秒数。How to read: measured on this Mac (Apple Silicon), not the HF leaderboard's H200/A100/CPU, so compare only within this board. Streaming granularity differs by project: Qwen3, VoxCPM2, Pocket, Audio8, MOSS and Breeze stream fixed-length audio chunks (interval column); IndexTTS streams completed text segments (not tokens), and a short sentence is one segment, so its first chunk is the whole sentence. A longer first chunk holds more audio, so do not read milliseconds alone.
