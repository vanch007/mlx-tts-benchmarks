按质量分排序。质量分只统计模型已测的能力，回答“它会的东西做得好不好”；全能分把不支持的能力按 0 计入，回答“一个模型能覆盖多少场景”；广度是已测出分数的能力数，语种是已评分的非中英语言数（共 40 种），覆盖率是模型支持的能力里已测出结果的比例。每格数字是该能力的分数。同一组内质量分相差 2.0 分以内的归为同一档（A、B、C…），请看档位而不是名次。这个宽度来自实测：内容、克隆、长文和 5 种公共语言共 28 道题每个模型各生成 3 次（换随机种子），质量分是 3 次的平均，“±”是 3 次之间的标准差，档宽取“两个平均值能可靠区分”所需的差距。表现力和副语言两个轴仍是每题一次。“公共5语”是日、韩、西、法、德五种语言的平均分，质量分里的多语种部分用它（不足 3 种时退回全部语种平均），冷门语言的表现只影响“多语种”一格和全能分。

评测是怎么做的

出题

84 道测试题，每题只归入一个能力维度；每个模型只安排它官方声明支持的题。

本地生成

所有模型都在同一台 Mac 上用 MLX 推理，记录音频和耗时（RTF）。

自动打分

ASR 转写算错字率，UTMOS 测自然度，两个声纹模型测克隆相似度。

加权汇总

每题打分（采样过的题取 3 次平均）→ 每个能力取平均 → 在模型已测的能力上按权重相加得到质量分，不支持的能力按 0 计入得到全能分。

质量分 = Σ(已测能力的平均分 × 已评比例 × 权重) ÷ Σ 已测能力的权重
全能分 = Σ(能力平均分 × 应测覆盖率 × 权重)，不支持、未测、待验证的能力计 0
质量分里，已评比例 = 可计分样本 ÷ 实际跑过的样本，生成失败会扣分，没安排的题不扣分。全能分的覆盖率按“应测题数”算，所以它同时反映质量和能力广度。方言轴按自动核验结果计分。同一模型同一题有多次运行时，只取最后一次成功的记录。

9 个能力维度与权重

能力权重怎么测
内容准确25%Qwen3-ASR 1.7B 转写后算错误率：中日韩泰等按字（CER），其他语言按词（WER）。
自然音质22%UTMOS 自然度预测，加上爆音、噪声底、静音、语速等波形检查。所有模型只在同一批中英核心题（朗读、长文、同语种克隆）上比较。
多语种12%40 种非中英语言朗读（原 8 种 + 32 种扩充）；每个模型只测它声明支持的语言，分数是这些语言的平均质量；会多少种语言单独列在“语种”一栏。高棉、老挝、缅甸语因 ASR 无法识别暂不计分。
方言3%粤语、四川话、上海话等方言朗读，用声学模型自动核验说的是不是目标方言：Qwen3-ASR 语种识别、Voxlect 方言分区分类器（川/豫/陕/鲁）、MMS-LID 语种识别（吴语、闽南语），粤语需前两者一致。上线前用 24 条普通话朗读方言文本做对照，三个模型误判均不超过 2 条，已知方言样本全部判对。判成普通话的记 0 分，判不准的不计分。东北话由人工盲听判定（含普通话对照）；北京话、天津话暂无可靠手段，不入分。
音色克隆17%ECAPA 与 CAM++ 两个声纹模型的相似度平均，再结合可懂度与自然度；任一模型判“不可用”即封顶。
表达控制10%声音设计、情绪、风格迁移、时长控制是否真的生效，需要任务内的直接证据。
复杂副语3%唱歌、笑声、叹气、呼吸等非朗读能力，同样需要直接证据。
段落连续性5%约 9–28 秒短段落的内容完整与重复检查；分钟级长文尚未测试。
RTF效率3%生成耗时 ÷ 音频时长（RTF），越低越快；复用全部正式样本。

目前还不能说明什么

  • 这是开发集上的工程验证，没有独立测试集和完整盲听；只有内容、克隆、长文和 5 种公共语言做了 3 次采样，表达控制和副语言仍是每题一次。分数是探索性代理，不是正式排名。
  • 方言、情绪、副语言缺少直接证据时记为“待验证”；长文只测了约 9–28 秒的短段落。
  • 音色克隆的声纹阈值只用本项目的少量参考音频校准过；克隆相似度只用声纹模型，不用 Gemini（相关性不足）。
  • 表达控制和副语言两个轴由 Gemini（gemini-3-flash-preview）判定情绪、笑声等是否出现。它能分清“有情绪”和“没情绪”（抽检 10/10 对 3/10），但分不出高低：有情绪的样本几乎都拿满分，所以这两个轴的分数差距很小，只能参考。原评委 gemini-2.5-flash 已对新 API key 关闭，所有控制样本都已改用这个模型重评。
  • 历史 RTF 的计时范围不完全一致，速度对比只能看量级。
